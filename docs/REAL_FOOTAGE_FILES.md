## Added Python dependencies

NumPy 2.2.6, SciPy 1.14.1, OpenCV 4.11.0.86, Supervision 0.25.1, ONNX Runtime 1.30.0, ImageIO-FFmpeg 0.6.0 and their transitive dependencies. PyYAML is reused. OpenCV DNN is the actual inference engine. Optional Ultralytics/PaddleOCR dependencies are listed separately and were not installed for plate inference. **No frontend runtime dependency was added.**

## Material limitations

No supplied plate detector/OCR weights or ground truth: accepted real plate identities, trajectories and alerts are empty, and accuracy is not measured. The sample-clip detector/tracker undercounts vehicles; output is labelled model estimates. Production auth, persistent rights handling, plate-model training, calibrated speed, navigation turn restrictions and government registry connectivity are not implemented. See `pipeline/README.md`, `docs/ACCURACY_REPORT.md` and `docs/PRIVACY_DPDP.md`.
